# 快速使用指南

这是本地单人配音工作台。先按[项目说明](../项目说明.md)安装依赖，以下命令在仓库根目录执行。当前真实模型为已配置的本机 CosyVoice3；声音效果仍待试听。

## 六步完成一份音频

1. **启动**：已构建时运行 `.venv/bin/python scripts/dev.py --built`，打开终端输出的本地页面。首次或更新前端后先运行 `npm --prefix frontend run build`。开发双服务使用 `.venv/bin/python scripts/dev.py`。Ctrl+C停止服务；不要让两份服务使用同一数据目录。
2. **准备参考**：创建项目，上传音频，试听后保存所需参考片段。上传原文件不等于选择片段。选择真实组件后会显示原话编辑区；真实生成还需填写该片段准确原话并保存；换切口后核对新的原话。
3. **准备文案**：逐段填写普通话原稿和武汉话草稿，保存，人工核对后确认。当前没有自动武汉话改写，复制原稿只是复制，不是改写。改稿后重新保存并确认。
4. **生成**：选择组件并核对其状态；建议先提交短段试听，也可直接生成全文。模拟测试音只验证流程，不朗读文字；实际配音选择已配置的真实组件。结果未知时核对原请求，失败按原输入重试，不把重试当作使用新稿。
5. **选用和返修**：每段试听版本，点击“选用此版本”。新生成不会自动覆盖原选用。改稿后可仅重生成本段，再核对前后段试听；保留旧版时过时警示持续存在。
6. **导出**：在“拼接与导出”核对已保存顺序及各段选用。段间新增静音默认0，可设0–2000毫秒；整篇含新增静音最多10分钟。下载整篇/单段 WAV和来源JSON。JSON记录来源，不能用于播放；不要把含模拟音的导出当真人配音。

## 更方便地启动

已构建时可运行 `.venv/bin/python scripts/dev.py --built --open`，就绪后自动打开默认浏览器。开发模式使用 `.venv/bin/python scripts/dev.py --open`。不加 `--open` 时手动打开显示的地址；浏览器打不开不会停止已启动的服务。

启动器先检查环境与端口，再等待页面、数据健康和开发代理可用（约30秒上限）。“服务已就绪”仅表示网站可用，不表示声音模型可用或声音满意。若已有服务占端口，在原启动窗口按 Ctrl+C 后重试；启动器不会结束其他进程。权限错误应检查终端/系统权限，不要删除数据。

开发模式会读取本机已登记的 Node 路径；路径失效时在可用 Node 的终端运行 `python3 scripts/check_app.py --configure-node`。缺少前端依赖运行 `npm --prefix frontend ci`；缺少构建运行 `npm --prefix frontend run build`；后端环境问题按项目说明安装。构建版启动不要求 Node，也不读取 Node 配置。服务日志保留在当前终端；失败或超时先检查日志，处理后重新运行同一命令。

## 常见情况

| 页面情况 | 操作 |
| --- | --- |
| 自动转换不可用 | 手工填写武汉话草稿，再人工确认 |
| 真实模型未配置或不可调用 | 按项目说明配置；可用模拟验证软件，不据模拟判断声音 |
| 有未保存内容 | 先保存；关闭页面前确认保存提示，退出提醒不等于自动保存 |
| 文案未确认 | 核对原意、数字、专名及草稿，确认后再生成或导出 |
| 整篇缺段 | 为每一段选择可用版本；已就绪段可单独导出 |
| 已过时或依赖未知 | 核对具体原因；可重新生成，或明确保留并确认导出，不会取消警示 |
| 多窗口输入或选择冲突 | 刷新并核对，不自动以旧窗口覆盖新数据 |
| 提交结果需要核对 | 先刷新历史，或重试同一导出请求；刷新/关闭后可从历史查找 |
| 下载提示文件不可用 | 检查原数据或备份，旧记录保留；不要手工改JSON伪造成功 |
| 感觉停顿太长 | 新增段间静音设0；它不会裁掉模型原本生成的停顿 |

## 项目整理与误操作恢复

项目详情新增“永久删除项目”：打开确认框核对项目与删除范围，再点“确认永久删除”。删除不可恢复，只清本项目应用内文案、上传副本、生成音频和导出；不动 Public 原始文件、模型、其他项目或独立备份。排队/运行任务或进行中的上传、下载、保存会阻止删除，请先处理或等待；未保存稿先保存或明确重新载入。

若提示结果待核对，可稍后从“继续核对删除”重试；同一标签整页刷新后仍保留该入口（浏览器会话存储可用时）。只有一项未决删除，须先核对再删其他项目。“项目已移除，文件待清理”表示数据库已删除、文件清理尚未完成，重试或重启会继续；不能理解为资料仍完整可恢复。旧项目链接也可核对清理状态。

项目详情可“归档项目”，随后在“已归档”列表打开并恢复。归档只整理列表，不删除素材、音频或历史，不取消正在执行的任务；未保存文案或参考原话须先保存。旧链接仍可访问归档项目。

复制原稿覆盖非空草稿前会询问确认；删除段落或复制后可撤销最近一次操作。最多200段；待撤销的删除段会保留一个位置，接近上限时请先撤销，或保存当前删除后再添加。保存失败仍保留撤销。撤销仅在本次编辑会话有效，保存或重新载入会清除；关闭页面不能依赖撤销找回未保存内容。

创建结果未知时，关闭再打开创建框仍可重试原请求。导出结果未知时暂禁新导出，保留原请求、段间静音与提示；同一窗口切项目、刷新组件后仍可核对并重试。刷新导出历史发现同项目、同请求且内容一致的可用成品后，会自动解除待核对，无需再次提交；不匹配或文件不可用仍保留原请求。整页刷新或关闭窗口不保留这些内存状态，请先核对项目列表或导出历史，避免再次新建。

## 保存与恢复

项目、素材、任务和导出保存在本机 `data/`，或 `VOICE_DATA_DIR` 指定目录。页面刷新不清空已保存数据。浏览器内尚未保存的草稿不能当作持久备份。

备份前先停止服务，再复制整个数据目录，连同 `.quality-local/model-runtime.json` 及所引用的配置归档一起保留。模型目录单独管理，旧任务按原配置重试需要相应环境。恢复前保留现有目录副本，使用与数据库版本匹配的代码；不要仅复制SQLite而漏掉音频，也不要删除数据库“修复”问题。

当前无自动备份、视频处理、字幕或多人协作功能。完整功能与限制以[项目说明](../项目说明.md)为准；独立声音实验按[接入交接](模型实验与接入交接.md)进行。

## 流程与下一步

首页“使用流程指南”是操作顺序，不是完成进度。“生成环节 · 下一步”依据本窗口读取的状态提示待处理事项；旧任务成功不表示当前稿已完成，须在版本和导出区核对缺段、过时与选用。跨窗口修改后请刷新核对。活跃列表为空仍可在已归档中查找和恢复项目。
