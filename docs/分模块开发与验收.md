## 检查入口

- `python3 scripts/quality_gate.py quick`：基础安全、语法及文档完整性，不检查机械路径白名单。
- `python3 -m unittest discover -s tests -v`：检查工具本身的回归。
- `python3 scripts/check_app.py --suite backend`：后端静态与行为测试。
- `python3 scripts/check_app.py --suite frontend`：前端静态与构建。
- `python3 scripts/check_app.py --suite browser --project desktop`：桌面浏览器；mobile同理，需先构建。
- `python3 scripts/quality_gate.py full`：按当前配置串行完整检查，手动按需执行，不要求审核JSON。

CI在独立环境并行后端与两组浏览器，保留零自动重试与失败工件。文档改动仅基础及治理检查。具体预算与检查实现以工作流和脚本为准，不在多处复制运行参数。
