# 团队协作与方案监督

现行流程以[协作规则](协作规则.md)为唯一依据，D054已取消逐批强制监督、全员签字及总验收/监督串行审批。旧审核文件保留历史，不作为新提交的强制凭证。

| 角色 | 按需职责 |
| --- | --- |
| root | 实施、协调共享资源、验证、记录与交付 |
| product | 用户流程及功能取舍 |
| architecture | 数据、并发、接口与运行结构 |
| speech | 模型能力与声音实验边界 |
| critic | 高风险改动的独立质量审查、异常路径与测试证据 |
| chief_acceptance | 复杂跨模块交付需要时汇总，非必经审批 |
| process_guardian | 发生方案偏离或治理问题时按需核对，非每批必审 |

复用现有负责人；仅调度与问题相关的角色，通常一次独立审查即可。代理只读审查，不与主持同时修改共享文件或运行共享测试。报告真实发现、证据与未测项；无关角色无需占位签署。审查范围变化只复核受影响内容，文档补记无需重新计算整仓摘要。
