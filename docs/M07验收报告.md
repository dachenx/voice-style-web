# M07 拼接与导出验收

## 范围与基线

基线 1dc2c1c，当前模块 M07，D036 授权暂停声音实验、保留模型接口并推进通用功能。主持唯一写入与验证；各角色只读审核。四职能与独立总验收已通过，最终摘要监督及正常本地提交随后核验。

## 已实现

- 按已确认稿顺序导出选用版本；单段/整篇 WAV 与来源 JSON；缺段、源文件损坏、未确认或未保存稿阻止创建。过时或依赖未知明确确认，确认不取消过时状态。
- 24k 单声道 PCM16，源 PCM 原样保留，只在段间加入0–2000毫秒静音，默认0；整篇含新增静音最多10分钟。模拟段标识保留，不自动增益、变速或裁静音。
- 读取事务冻结比较 token、选用 revision、段序及来源；退出事务后校验音频并写文件。服务内导出锁协调同请求重放；临时目录完成后原子发布，无数据库迁移。来源清单含内容摘要、当前与实际生成文字、版本依赖、帧位置。
- 响应丢失可重放同请求；旧音频和导出不覆盖。重启在服务目录锁内清理未发布临时目录。历史损坏标不可用；进程中断恢复不等于断电耐久保证。

## 职能意见

- product：实际源码审查通过，无新增业务取舍；测试与截图证据来自主持，未亲跑。
- speech：实际PCM拼接、来源与模拟标识审查通过；未试听，不签声音自然度。
- architecture：最终复核通过，已核主导出源段校验/拼接写出及幂等重放全量校验均移到事务外（读取快照仍核当前参考片段），严格revision与屏障、进程中断恢复有实际覆盖；未亲跑测试。
- critic：指出迟到历史清错误与初始就绪竞态，已修并补浏览器覆盖，最终质量通过；仅只读核源码与断言，测试依据主持回执。
- process_guardian：初审缺陷修正后的阶段监督通过，已核事务外导出音频处理及回归断言；最终冻结摘要待总验收后核定。
- chief_acceptance：独立总验收无待用户决策问题，已核源码、差异与断言；选择确认、输入冻结、拼接来源、发布恢复、界面交接逐环节通过软件范围。测试依据主持真实工具回执，不声称亲跑或读取不存在的日志；准予最终摘要监督及轻量提交。

## 使用与后续模型接入

保存并确认文案，在段落版本中逐段选用，再到“拼接与导出”设置新增静音，导出整篇或单段。历史提供 WAV 与来源记录下载。旧全文任务无段边界，仍从任务记录下载，不猜切口。

模型生成接口保持原样，本轮不新增模型参数或云端调用。另一声音实验可独立保留材料和证据；未经协调不要并发改共享生产代码或数据。后续正式接入须验证能力、标准输出与依赖身份，不能把实验样音当已接入。M08 人物音色、武汉话、长文稳定与模型性能仍单独待验收。

仅本地提交，不推送GitHub。回退程序前先停止服务并备份数据；无数据库迁移，导出目录为新增数据，可保留供升级后读取，不应删除旧素材和生成结果。
