## 独立实验怎么做

- 一个模型使用独立目录、环境、缓存和资源清单，避免修改现有模型环境。冻结准确原话、参考摘要、测试文案、模型版本/权重摘要、参数/随机条件及调用方式。
- 先写比较对象、主要变量、样本上限和停止条件；保存原始输出、耗时、错误与人工评价。机器转写不能替代声音听审，不能用文件可播放证明方言正确。
- 不并发改共享生产源码、模型配置指针、项目数据库、参考素材或正式任务结果。实验在独立目录运行；若需要修改正式项目，先交接唯一写入方。当前仍只做本地Git，上传另外安排。
- 确认候选不适用后，按用户约定停止自有进程并清理该候选新增的独占权重/环境/缓存；保护原件、样音、结论及共享依赖。不能确认归属时先保留，不因暂时网络失败淘汰声音模型。

## 已保留的接口及实际限制

已有 `GenerationAdapter.capability` 与 `generate(snapshot, destination, progress)`，以及组件注册、任务快照、结果校验和版本比较。**有接口不等于新模型注册后即插即用。**

- `backend/app/generation.py` 目前只接受空参数 `{}`。新模型的语言、语速、情绪、参考长度及准确原话要求须单独声明并验证，不伪造支持。
- 入队、冻结配置、实际执行与历史重试目前对 `LocalCosyVoiceAdapter` 和 `LocalQwenAdapter` 有明确处理。新真实模型必须适配这些路径，不能简单继承其他组件的默认“可用”健康结果。
- 配置有效、执行可用、模型加载、生成成功、声音满意是不同状态。必须实现错误、超时及自有进程回收；不得把模型异常伪装为模拟成功。
- worker会核对能力与快照。修改能力字段/default可能影响旧任务及重试，需版本兼容和回退安排，不能静默使用新配置重试旧快照。
- `backend/app/versions.py` 的依赖比较只认识现有组件。新模型须明确实际使用的文本、参考、参数、模型/环境身份及上下文范围；使用前文的模型可能使后续多段过时，不能默认只影响修改段。
- 新结果须符合 `paragraphs-v1`：真实分段文件、UUID与顺序、完整PCM及摘要。当前产品标准是24k单声道PCM16，转换由适配器明确处理并验证；不能靠猜静音边界把整篇冒充分段输出。
- 导出模块读取已选标准产物，无需直接调用模型。换模型仍须验证输出、来源、过时识别及旧产物可用，不能借“导出通用”跳过接入验收。

## 带回主项目的交接内容

提供模型及许可证、免费使用条件、运行方式与资源清单；准确输入及输出摘要、可复现调用、用户听审结论和保留的问题；需要支持的能力、上下文依赖、配置冻结、失败恢复与回退方案。

正式接入按“独立效果证据 → 契约与配置 → 生命周期 → 快照及依赖 → 分段产物 → 故障/兼容/UI验证”推进。仅有好听样音不等于已接入，软件验收通过也不代替M08声音评分。当前没有承诺任意模型、任意方言或任意长文效果。
