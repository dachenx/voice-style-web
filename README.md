# 声作 · 本地配音 Web

一个在本机运行的配音工作台：创建项目，输入或导入要朗读的文案，选择已配置的人物声音，生成、试听和选用音频，再按段落顺序拼接导出 WAV。

当前接入人物版本 **万先生-Qwen3v0.11-武汉话**，也支持 CosyVoice3 自选参考声音。人物模式由后台绑定固定参考，使用时无需为每个项目重复上传录音。声音相似度、武汉话语气和自然度仍在独立调试中。

> 本仓库包含 Web 源码和模型对接程序，不包含模型权重、人物参考录音、生成音频、私人配置或数据库。下载源码后需要安装依赖并另行准备模型资源，才能真实配音。模拟组件只生成测试音，不朗读文案。

## 功能特性

- **项目管理**：创建、重命名、归档恢复及二次确认永久删除，数据保存在本机。
- **文案输入与导入**：直接输入文字，或导入 TXT、Word `.docx`，预览后替换当前段；高级编辑支持分段与排序。
- **人物与参考声音**：选择固定人物版本，或为自选参考组件上传音频、试听、选段并记录准确原话。
- **配音任务**：生成前保存并确认本次文案，按本地单任务队列执行，显示进度、失败原因及重试入口。
- **版本与局部返修**：保留多个候选，逐段试听和选用；改稿后可只重生成需要修改的段落，旧版本明确提示过时。
- **拼接与导出**：按已保存的段序拼接选用音频，设置额外段间静音，试听并下载整篇或单段 WAV，以及来源 JSON。
- **任务清理**：二次确认删除终态任务及生成音频；已被选用或导出引用时阻止删除。
- **异常恢复**：未知提交可核对原请求，清理失败可重试，持久历史在重启后继续读取。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | React 19、TypeScript、Vite |
| 后端 | Python、FastAPI |
| 数据存储 | SQLite 与本地文件目录 |
| 任务执行 | 本地工作进程、持久任务队列 |
| 语音适配 | Qwen3 人物版本、CosyVoice3、模拟测试组件 |
| 音频处理 | FFmpeg、WAV 拼接与来源记录 |
| 质量检查 | pytest、Playwright、Ruff、mypy、ESLint、TypeScript |

## 本地运行

需要 **Python 3.11+、Node.js 22.12+ 和 Git**。以下命令用于 macOS/Linux，在仓库根目录执行：

```sh
git clone https://github.com/dachenx/voice-style-web.git
cd voice-style-web
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.lock
npm ci --prefix frontend
npm --prefix frontend run build
.venv/bin/python scripts/dev.py --built --open
```

启动就绪后打开 **http://127.0.0.1:8000**，按 `Ctrl+C` 停止服务。已有服务占用端口时，先在原终端关闭它。Windows 的虚拟环境程序位于 `.venv/Scripts/`，详细环境说明见[项目说明](项目说明.md)。

开发前端时可使用 `.venv/bin/python scripts/dev.py --open`，开发页面为 **http://127.0.0.1:5173**；更新前端后，构建模式需要重新执行 `npm --prefix frontend run build`。

**网站启动成功不等于模型已经就绪。** 真实生成需单独配置模型环境、权重及参考资源，详见[项目说明](项目说明.md)和[模型实验与接入交接](docs/模型实验与接入交接.md)。未准备好模型时可用模拟组件检查软件流程。

## 使用流程

1. 创建或打开项目，选择已配置的人物或语音组件。
2. 在文案框输入内容，或导入 TXT / Word `.docx` 并核对预览。
3. 点击生成，等待任务完成并试听；需要调整时修改对应段落后重新生成。
4. 为每段选用一个音频版本，再核对拼接顺序和段间静音。
5. 导出、试听并下载 WAV。详细操作见[快速使用指南](docs/快速使用指南.md)。

## 当前限制

- 初版面向本地单人使用，不提供多人账号或云端部署管理。
- 不自动转换或改写武汉话文案，按用户输入的文字生成。
- 人物 v0.11 每段最多 80 个文字字符（含标点），长稿需手工分段；语速、情绪和读音控制尚未接入。
- Word 仅支持 `.docx` 正文普通段落，不提取表格、页眉页脚或图片文字；旧 `.doc` 需先另存为 `.docx`。
- 只能取消排队任务，运行中任务尚无停止入口；独立参考素材清理仍待完善。
- 段间静音只额外增加停顿，不会裁掉模型生成的原有停顿；软件检查通过不代表声音效果达标。

项目数据默认存放在本机 `data/`。备份时应先停止服务，完整保存数据目录、私有模型配置及其引用资源。不要删除数据库来处理启动错误。
